# 代码知识图谱 GitNexus

> 项目地址：<https://github.com/abhigyanpatwari/GitNexus>

## 一句话介绍

一个代码智能引擎，把任意代码库索引为**知识图谱**，为 AI 编程助手（Cursor、Claude Code、Codex、Windsurf 等）提供深度的架构感知能力。官方定位：**Building nervous system for agent context**——让 AI 修改代码时不遗漏依赖关系、不破坏调用链。

## 核心功能

- **知识图谱索引**：抓取文件、函数、类、接口、导入、继承、调用链等关系。
- **16 个 MCP 智能工具**，包含：
  - `impact`：影响范围（blast radius）分析
  - `query`：混合搜索（BM25 + 语义 + RRF）
  - `context`：符号的 360° 视图
  - `detect_changes`：Git diff 影响检测
  - `rename`：多文件协调重命名
  - `cypher`：原生图查询
- **社区检测与流程追踪**：通过 Leiden 聚类识别功能模块，追踪执行流。
- **Wiki 生成**：基于图谱生成 LLM 驱动的文档。
- **多仓库支持**：全局注册表，一个 MCP server 服务多个已索引 repo。
- **两种形态**：CLI + MCP（本地开发）与 Web UI（浏览器可视化探索）。
- **支持语言**：TypeScript、JavaScript、Python、Java、Kotlin、C#、Go、Rust、PHP、Ruby、Swift、C、C++、Dart。

## 技术栈

| 层 | CLI | Web |
|---|---|---|
| 运行时 | Node.js | 浏览器（WASM） |
| 解析 | Tree-sitter 原生绑定 | Tree-sitter WASM |
| 数据库 | LadybugDB 原生 | LadybugDB WASM |
| 嵌入 | transformers.js (GPU/CPU) | transformers.js (WebGPU/WASM) |
| 搜索 | BM25 + 语义 + RRF | 同左 |
| Agent 接口 | MCP (stdio) | LangChain ReAct |
| 可视化 | — | Sigma.js + Graphology (WebGL) |
| 前端 | — | React 18、TypeScript、Vite、Tailwind v4 |

## 安装

```bash
给你的ai agent 说 帮我全局安装 https://github.com/abhigyanpatwari/GitNexus 这个 skill
```

其它方式（在仓库根目录运行）：

```bash
npx gitnexus analyze   # 一条命令完成索引 + 安装 agent skills + 注册 Claude Code hooks + 生成 AGENTS.md/CLAUDE.md
npx gitnexus setup     # 自动检测编辑器并写入全局 MCP 配置（Claude Code / Cursor / Antigravity / Codex / Windsurf / OpenCode）
```

> npm 11.x 有已知问题，可改用 pnpm，或全局安装 `npm install -g gitnexus` 绕过。

## 使用

**常用命令**：
- `gitnexus analyze` — 索引或增量更新
- `gitnexus mcp` — 启动 MCP server（stdio）
- `gitnexus serve` — 启动本地 HTTP server 供 Web UI 连接
- `gitnexus list` / `status` / `clean` — 管理索引
- `gitnexus wiki` — 生成文档
- `gitnexus group ...` — 多仓库 / monorepo 分组管理

**Web UI**：
- 访问 <https://gitnexus.vercel.app>
- 或本地 `npx gitnexus@latest serve` 后自动连接
- 也可 `docker compose up -d` 启动官方镜像（server `:4747`，UI `:4173`）
